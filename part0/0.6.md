# Exercise 0.6: New note in Single page app diagram

```mermaid
sequenceDiagram
    participant browser
    participant server

    Note right of browser: User types the note and clicks Submit.<br/>JS adds note to local list and redraws notes on screen.

    browser->>server: POST https://studies.cs.helsinki.fi/exampleapp/new_note_spa
    activate server
    Note right of browser: Payload: {"content": "My new note", "date": "2026-10-5..."} 
    server-->>browser: 201 Created {"message": "Note created"}
    deactivate server

    Note right of browser: New note rendered by JavaScript. <br/>No need to refresh the page or send a new request!
```
